# 💬 Sentiment Analysis of Social Media Comments

This project applies natural language processing (NLP) techniques to classify the sentiment of social media comments. It demonstrates how to clean and vectorize text data, build a classification model, and visualize sentiment trends.

---

## 🧠 Techniques Used
- Text preprocessing (stopword removal, tokenization)  
- TF-IDF vectorization  
- Sentiment classification using machine learning  
- Word cloud visualization

---

## 🛠 Tools & Technologies
- Python (pandas, scikit-learn, nltk)  
- WordCloud for visualization  
- Jupyter Notebook

---

## 📄 Files Included
- `Sentiment_Analysis.ipynb`: Jupyter notebook containing the full sentiment analysis workflow

---

## 📊 Key Insights
- Cleaned and vectorized user comments for model training  
- Built a classification model to predict positive or negative sentiment  
- Visualized frequent words using word clouds  
- Evaluated model performance using accuracy and confusion matrix

---

## 📌 Summary

This project showcases how NLP and machine learning can be used to extract sentiment from unstructured text data. It’s a practical example of turning raw comments into actionable insights, useful for brand monitoring, customer feedback analysis, or social media listening.
