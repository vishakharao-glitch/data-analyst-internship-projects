# 🌸 Iris Dataset – Exploratory Data Analysis

This project performs exploratory data analysis (EDA) on the classic Iris dataset using Python. It focuses on understanding the structure of the data, identifying patterns, and visualizing relationships between features.

---

## 🧠 Techniques Used
- Data cleaning and preprocessing  
- Summary statistics and distribution analysis  
- Feature comparison and correlation  
- Visual storytelling with plots

---

## 🛠 Tools & Technologies
- Python (pandas, numpy)  
- Seaborn and Matplotlib for visualization  
- Jupyter Notebook

---

## 📄 Files Included
- `EDA_Iris_Analysis.ipynb`: Jupyter notebook containing the full analysis

---

## 📊 Key Insights
- Distribution of petal and sepal measurements across species  
- Pairwise relationships between features using scatter plots  
- Species-wise comparison using boxplots and violin plots  
- Correlation matrix to identify feature dependencies

---

## 📌 Summary

The Iris dataset is a foundational dataset in data science, and this project demonstrates how to explore it effectively using Python. The analysis provides a clear understanding of how different flower species differ in terms of petal and sepal dimensions, and sets the stage for future classification tasks.
